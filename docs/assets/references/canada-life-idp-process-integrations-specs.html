Payload Specifications & Metadata Parameters

Strict field typing and structural requirements for triggering PROC-GH-8820.

Content-Type: multipart/form-data
Parameter Type Requirement Constraints & Schema Description
file Binary Required PDF, TIFF, JPEG • ≤ 50MB Single or multi-page claim packet including receipts and claim forms.
priority Enum (String) Optional standard | expedited Defaults to standard. Expedited moves queue priority to tier 1 high-throughput pool.
external_batch_id String Optional Max 64 ASCII chars Client tracking identifier propagated through all subsequent webhook and audit events.
callback_url HTTPS URI Recommended Valid HTTPS • Internal TLS signed Receives asynchronous notification dispatch upon job completion, exception, or HITL routing.
document_type_hint String Enum Optional CL-CLAIM-04-A | CL-CLAIM-04-B Bypasses automatic document classifier, accelerating first-pass processing time by ~400ms.

Standard HTTP Fault Codes

All client errors adhere to RFC 7807 problem details specifications.

400
Bad Schema / Missing Metadata
Occurs when required metadata parameters are missing or invalid JSON formatting is detected.
413
Payload Too Large
File size exceeds the 50MB per-request threshold. Use chunked SFTP batch drops for larger files.
422
Corrupted File / Password Protected
Encrypted PDF documents without passkey clearance or unrenderable corrupt TIFF headers.
